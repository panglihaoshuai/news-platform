# Global Intel Map - Bloomberg Terminal War Room Design
## 设计规范文档 v1.0

---

## 1. 设计愿景

**产品定位**: 类似彭博终端的专业金融情报终端，为理性投资者提供全球实时热点态势感知。

**核心体验**:
- **沉稳**: 不花哨，专业严肃
- **准确**: 数据实时，信息可靠
- **优雅**: 界面精致，动效流畅
- **自然**: 副屏静默显示时不打扰

**参考风格**: Bloomberg Terminal + NASA Mission Control + 军事战情室

---

## 2. 布局架构

### 2.1 基础布局（标准模式）

```
┌─────────────────────────────────────────────────────────────┐
│ TICKER BAR (滚动新闻条)                                      │
│ [LIVE] [GLOBAL] [滚动: P0事件 ▶ P1事件 ▶ P2事件...]         │
├──────────────────────────┬──────────────────────┬───────────┤
│                          │                      │ MARKET    │
│    🗺️ MAP (60%)          │   NEWS (30%)         │ DATA      │
│    主视觉地图区域         │   新闻列表            │ (可折叠)  │
│                          │                      │           │
│  • 脉冲热点标记           │  • P0-P3优先级       │ 股指/商品  │
│  • 区域边界高亮           │  • 时间线排序         │ 汇率/债券  │
│  • 航线/流向动画          │  • 分类标签          │           │
│                          │                      │           │
├──────────────────────────┴──────────────────────┴───────────┤
│ STATUS BAR (状态栏)                                          │
│ [🟢 Online] [🔄 Updated: 14:32:05] [🕐 Local: 14:32:05 CST] │
│ [📊 127 Events] [⚡ 23ms]                                    │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 三种显示模式

**模式1: 标准模式** (默认)
- 左右分栏布局
- 地图60% + 新闻30% + 市场数据10%(可折叠)
- 适合主动筛选和阅读

**模式2: 紧凑模式** (彭博终端)
- 高密度信息展示
- 市场数据固定显示
- 新闻列表更紧凑
- 适合副屏监控

**模式3: 沉浸模式** (战情室)
- 地图最大化(85%)
- 新闻列表悬浮/最小化
- 仅显示关键控制
- 适合大屏展示

切换方式: `Tab` 键 或 界面按钮

## 3. 色彩系统

### 3.1 主题1: Bloomberg Terminal (默认)

**背景色**:
- 主背景: `#000000` (纯黑)
- 次背景: `#0a0a0f` (极深蓝黑)
- 卡片背景: `#111118` (深灰蓝)
- 分隔线: `#1a1a24`

**文字色**:
- 主文字: `#e0e0e0` (灰白)
- 次文字: `#8b8b9a` (中灰)
- 弱化文字: `#5a5a6b` (深灰)

**强调色** (彭博荧光):
- 上涨/正面: `#00ff41` (荧光绿)
- 下跌/负面: `#ff3333` (警示红)
- 中性/信息: `#00d4ff` (电光蓝)
- 警告/注意: `#ffaa00` (琥珀黄)

**优先级色**:
- P0 (紧急): `#ff0000` + 脉冲动画
- P1 (重大): `#ff6600` + 呼吸效果
- P2 (关注): `#ffcc00`
- P3 (一般): `#666666`

### 3.2 主题2: 护眼琥珀模式

**背景色**:
- 主背景: `#1a1a1a` (深灰)
- 次背景: `#242424`

**强调色** (琥珀):
- 上涨/正面: `#ffb347` (柔和橙)
- 下跌/负面: `#ff6b6b` (柔和红)
- 中性/信息: `#87ceeb` (天蓝)

### 3.3 主题3: 明亮专业模式

**背景色**:
- 主背景: `#f5f5f5` (浅灰)
- 次背景: `#ffffff` (白)

**文字色**:
- 主文字: `#1a1a1a` (深黑)
- 次文字: `#4a4a4a` (中灰)

## 5. 组件设计

### 5.1 TICKER BAR (滚动新闻条)

**位置**: 顶部固定
**高度**: 32px
**功能**: 
- 从左向右滚动显示最新事件
- P0事件红色高亮闪烁
- 点击可跳转到地图对应位置

**视觉**:
```
[🟢 LIVE] [GLOBAL] ▶ 🔴P0 台湾地震7.5级 海啸预警 ▶ 🟠P1 美联储暗示降息 纳指上涨 ▶ 🟡P2 SpaceX星舰入轨...
```

### 5.2 MAP (地图区域)

**核心功能**:
- 深色底图 (MapTiler Dark)
- 热点脉冲标记 (P0红色脉冲, P1橙色呼吸)
- 区域热力着色
- 航线/流向动画

**交互**:
- 滚轮缩放
- 拖拽平移
- 点击热点显示详情
- 双击聚焦区域

**自动功能**:
- Auto-Pilot: 每10秒切换到下一个热点
- 最近更新优先显示

### 5.3 NEWS LIST (新闻列表)

**布局**:
- 垂直时间线
- 卡片式条目
- 按优先级分组

**条目样式**:
```
┌─────────────────────────────────────┐
│ 🔴 P0 | 14:32:05                    │
│ 台湾发生7.5级地震 多国发布海啸预警   │
│ 军事, 社会 | Reuters | 台湾         │
└─────────────────────────────────────┘
```

**自动行为**:
- 新条目顶部插入 (淡入动画)
- P0条目自动展开
- 支持手动标记已读

### 5.4 MARKET DATA (市场数据面板)

**位置**: 右侧可折叠面板
**默认**: 折叠 (仅显示按钮)
**展开**: 显示实时市场数据

**内容**:
```
┌─ MARKET DATA ─┐
│ S&P 500  4,850 ▲0.3% │
│ NASDAQ  15,420 ▲0.5% │
│ GOLD   $2,034 ▼0.2%  │
│ OIL     $78.5 ▲1.1%  │
│ BTC  $43,200 ▲2.4%  │
│ USD/CNY 7.21 ▲0.1%  │
└─────────────────────┘
```

**特性**:
- 实时价格更新 (WebSocket)
- 涨跌颜色编码
- 与新闻事件的相关性高亮

### 5.5 STATUS BAR (状态栏)

**位置**: 底部固定
**高度**: 28px

**内容** (从左到右):
```
[🟢 Online] [🔄 Updated: 14:32:05 UTC] [🕐 Local: 14:32:05 CST] [📊 127 Events] [⚡ 23ms Latency] [Theme: ■ ■ ■]
```

**功能**:
- 显示系统在线状态
- 最后更新时间 (UTC)
- 本地时区时间
- 当前显示事件数
- 网络延迟
- 主题切换按钮

## 6. 动效设计

### 6.1 原则
- **克制**: 不花哨，功能性动画
- **快速**: 150-300ms 微交互
- **有意义**: 每个动画都有目的

### 6.2 具体动画

**热点脉冲** (P0事件):
- 红色同心圆扩散
- 周期: 2秒
- 透明度: 100% → 0%
- 大小: 20px → 60px

**呼吸效果** (P1事件):
- 橙色光晕缩放
- 周期: 3秒
- 缩放: 1.0 → 1.2 → 1.0

**新条目插入**:
- 淡入 + 下滑
- 持续时间: 200ms
- 缓动: ease-out

**Ticker滚动**:
- 平滑水平滚动
- 速度: 50px/s
- 无缝循环

**数据更新**:
- 数字变色闪烁 (绿/红)
- 持续时间: 500ms
- 背景高亮后淡出

## 7. 响应式设计

### 7.1 断点
- 大屏: ≥1440px (完整布局)
- 中屏: 1024-1439px (紧凑布局)
- 小屏: <1024px (仅列表/地图切换)

### 7.2 副屏优化
- 默认进入"紧凑模式"
- 减少动画以节省资源
- 自动刷新间隔延长到30秒

## 8. 交互模式

### 8.1 键盘快捷键

| 按键 | 功能 |
|------|------|
| `Tab` | 切换显示模式 (标准/紧凑/沉浸) |
| `Space` | 暂停/恢复 Auto-Pilot |
| `↑/↓` | 新闻列表上下滚动 |
| `←/→` | 切换区域筛选 |
| `F` | 切换全屏 |
| `T` | 切换主题 |
| `M` | 展开/折叠市场数据 |
| `R` | 刷新数据 |
| `?` | 显示快捷键帮助 |

### 8.2 鼠标交互

- **左键点击**: 选择热点/新闻
- **右键点击**: 显示上下文菜单
- **滚轮**: 缩放地图
- **拖拽**: 平移地图

## 9. 技术实现要点

### 9.1 性能优化
- 地图使用 WebGL (MapLibre)
- 虚拟滚动新闻列表 (只渲染可视项)
- 防抖筛选操作
- WebSocket 实时数据推送

### 9.2 主题切换
- CSS Variables 定义所有颜色
- 切换时平滑过渡 (300ms)
- 保存用户偏好到 localStorage

### 9.3 实时更新
- 服务器推送新事件 (Supabase Realtime)
- Ticker WebSocket 连接
- 市场数据每5秒刷新
